MVT Rendering Architecture 설계 — Paint/Layout 로직 분리.
지도 벡터 타일(MVT)은 Layer 타입이 제각각이라 단일 Pipeline으로 다 받아내기가 어려웠음. Paint(스타일)와 Layout(지오메트리)을 분리하고 Layer 타입별(Fill·Line·Fill-Extrusion·Symbol) Pipeline을 따로 세운 다음, MVT Parser는 그 위에서 계속 재사용 가능하도록 만듦.
Style 타입별 VBO 통합 → Draw Call 90%+ 감소.
레이어마다 VBO를 따로 그리다 보니 Style 종류가 늘 때마다 Draw Call도 같이 늘어났음. 같은 Style Type끼리는 VBO를 하나로 합쳐서 한 배치로 그리도록 바꿈.
Ear Clipping 동적 할당 제거 — Static Memory Pool로 Frame-time Spike 잡음.
Ear Clipping이 매 프레임 동적 할당을 일으켜서 스파이크가 났음. 정적 Memory Pool로 할당 방식 자체를 바꿔서 원인을 없앰.
glTF·KTX Pipeline 구축, KTX·ASTC 전환 → 로딩 성능 70~80%↑.
기존 텍스처 포맷은 로딩 시간과 용량 둘 다 아까웠음. KTX·ASTC 압축 포맷으로 바꾸고, 그 김에 GPU 기반 Skinning Shader도 같이 붙임.
실시간 내비게이션용 Kotlin–C++ JNI Bridge · gRPC 통신 Layer 구현.
Android 앱(Kotlin)과 엔진(C++)이 내비게이션 데이터를 실시간으로 주고받아야 해서, 그 사이를 JNI Bridge와 gRPC로 연결함.
